# 🎓 Sistema MANDEL.IA

**MANDEL.IA** es una aplicación de escritorio de arquitectura *offline-first* diseñada para optimizar la gestión académica, el registro de matrícula y el control de aulas de computación en el **Complejo Educativo Estatal "Nelson Mandela"**.

El sistema opera de manera completamente local sin depender de conexión a internet, integrando una base de datos relacional robusta y un asistente de inteligencia artificial ejecutado en el propio equipo para facilitar consultas administrativas y soporte educativo.

## 🚀 Características Principales
* **Operación 100% Offline:** Diseñado para funcionar en entornos sin conectividad estable, garantizando disponibilidad total de los datos.
* **Gestión Académica y Administrativa:** Control estructurado de registros de estudiantes, personal docente y recursos de la institución.
* **Asistente de IA Local:** Integración con modelos de lenguaje locales mediante **Ollama** para consultas rápidas, análisis de información y asistencia en tiempo real.
* **Interfaz Ligera y Moderna:** Aplicación de escritorio fluida construida con tecnologías web empaquetadas de bajo consumo de recursos.

## 🛠️ Stack Tecnológico
* **Backend:** Python
* **Frontend / Interfaz:** HTML5, CSS3, JavaScript (WebView)
* **Base de Datos:** PostgreSQL
* **Inteligencia Artificial:** Ollama (LLM local)

## 📋 Contexto del Proyecto
Desarrollado como parte del proyecto de Servicio Comunitario Universitario (T.S.U. en Informática), orientado a la modernización tecnológica y el soporte de infraestructura en instituciones educativas públicas.
